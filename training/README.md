# Local training sources

Keep your personal PDF copies in this directory. Source IDs, filenames, release labels and page counts are registered in `src/main/workbook-catalog.ts`. PDFs are ignored by Git and are not bundled with the app. Their filenames must match the catalog for **Open local PDF** to work.

The Linux curriculum uses the System Administration I and II workbooks, the RHEL 10 administration study guide, and topic adaptations from the legacy diagnostic notes. The language-models book is outside this curriculum.

Lessons, explanations, help and review questions are original adaptations. A workbook reference identifies a section and physical PDF page range; printed page numbers can differ. See [the coverage map](../docs/TRAINING.md).
