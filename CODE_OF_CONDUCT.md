# RHELboat code of conduct

Help make RHELboat a useful, welcoming place to learn Enterprise Linux.

- Treat people with respect, including those with different experience levels or views.
- Discuss the work without personal attacks or disparaging remarks.
- Assume good intent, accept corrections, and give feedback people can act on.
- Do not harass others or publish private information.

These expectations apply to repository issues, pull requests, and other project spaces. Raise concerns with the repository maintainers; avoid publishing sensitive personal details in a public report.

This code of conduct retains principles from the upstream project's policy, which was derived from [Ladybird](https://github.com/LadybirdBrowser/ladybird/blob/master/CODE_OF_CONDUCT.md).
